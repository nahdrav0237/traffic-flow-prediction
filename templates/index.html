About this project

This system uses an Optimized Random Forest Regression model to predict traffic volume.

The model was trained using the UCI Metro Interstate Traffic Volume dataset containing 48,204 observations.

The model was improved using hyperparameter tuning to achieve better prediction performance.

Model R² Score: 92.84%

Mean Absolute Error (MAE): 290.86 vehicles/hour

Root Mean Squared Error (RMSE): 526.45 vehicles/hour
